### 🔐 CarePoint Clinical - Azure Security Project

A hands-on Azure project where I built and secured a cloud storage environment for a fictional healthcare organization.

For this project, I created an Azure Storage Account and worked with role-based access control (RBAC) to manage access to clinical data. I also configured security settings such as HTTPS-only traffic, TLS 1.2, encryption, restricted public access, and network access controls.

I used Azure Log Analytics to review storage activity and see successful and failed authorization attempts. This helped me get practical experience with Azure permissions, storage security, monitoring, and troubleshooting.

**Tools used:** Azure Storage, Azure RBAC, Microsoft Entra ID, Log Analytics, Azure CLI, PowerShell
